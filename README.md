# Proxy-Multi-Curve-Treasury-Swap-Risk-Analytics-Framework
Bootstrapping · Interpolation · DV01/KRD · 2022 Stress Test PCA Decomposition · Multi-Curve Repricing · Factor-Based P&amp;L Attribution
## Overview
This project builds a fixed income analytics workflow using U.S. Treasury and swap data.

## Main Features
- Treasury zero-curve bootstrapping
- DV01 / KRD
- 2022 stress testing
- PCA decomposition
- Proxy multi-curve swap repricing

## Key Results
- Portfolio DV01: $392,635 per 1bp
- 2022 stress P&L: -$111.02M
- First 3 PCA factors explain 95.59%
- IRS repricing error within about 2.7-2.8 bps

## How to Run
Open the notebook and run the cells sequentially.
